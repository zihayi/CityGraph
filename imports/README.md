# 杭州西湖周边街道

## 完整区域样例（推荐框选后导入）

`hangzhou-west-lake-full.osm`：同一范围的完整 OSM 区域提取，约 11.08 MB。已通过 CityGraph 导入器验证，包含 4,519 个道路对象、5,373 栋建筑、349 个水域分片、1,021 个绿地分片、427 个用地分区及 865 个设施。15 处不完整引用和 7 处无效几何会在导入预览中提示并跳过。

在导入预览中框选一小块区域，再选择“添加到当前地图”，即可合并到现有存档。带岛屿或内孔的区域会分成多个保留空洞的可编辑分片，因此图层对象数量与 OSM 原始对象数量可能不同。

## 街道样例

- 文件：`hangzhou-west-lake-streets.osm`
- 数据来源：OpenStreetMap 官方 API，分四块下载后合并、去重并提取道路。
- 实际下载接口：`https://api.openstreetmap.org/api/0.6/map?bbox=西经度,南纬度,东经度,北纬度`。四块以经度 120.1465°E、纬度 30.2450°N 为中线；例如西南块为 <https://api.openstreetmap.org/api/0.6/map?bbox=120.1170,30.2190,120.1465,30.2450>。
- 导出时间：2026-09-18。
- 选区：南界 30.2190°N、北界 30.2710°N，西界 120.1170°E、东界 120.1760°E。
- 内容：选区内的街道、步行路、自行车道及其完整节点，包含湖滨路、南山路、北山街一带。
- OSM 按道路对象提取，边界上的道路可能延伸到选区之外。
- 导入方法：CityGraph → 设置 → 城市与存档 → 导入 OpenStreetMap → 选择上述 `.osm` 文件。
- 来源署名：© OpenStreetMap contributors，数据许可 [ODbL](https://www.openstreetmap.org/copyright)。

文件大小约 2.54 MB，包含 4,519 个 OSM 道路对象及 22,988 个节点。已使用 CityGraph 导入器校验，可转换为 9,652 个可编辑道路段，未发现缺失节点或跳过项。包括湖滨路、南山路、北山街、杨公堤、苏堤和白堤。

查询保存在 `hangzhou-west-lake-streets.overpass`，可粘贴到 <https://overpass-turbo.eu/> 重新获取数据。

完整区域文件保留四块数据中的节点、道路和关系，并按 OSM 类型与 ID 去重。水域内孔在导入时转换为可编辑分片；显示时会将同一 OSM 水体的分片合并绘制，只显示一次名称及实际岸线，已有存档也适用。
