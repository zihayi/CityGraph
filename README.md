CityGraph 是一款中文友好的二维城市地图创作工具。你可以手绘道路与建筑、规划功能分区、组织大学和医院、布置企业与公共设施，也可以下载真实的 OpenStreetMap 街区，放进自己的城市继续改造。

这里的主要玩法是**创作、编辑和完善城市地图**。大学排名、企业市值、行政区 GDP 等信息由你设定；目前没有居民、资金收支或交通流量的自动模拟。

## 第一次启动

**Windows 玩家直接双击主目录下的 `CityGraph.exe` 即可开始，不需要安装 Node.js、npm 或 Rust。**

1. [下载 CityGraph.exe](https://github.com/zihayi/CityGraph/raw/refs/heads/main/CityGraph.exe)。
2. 放到自己有写入权限的文件夹，例如 `D:\Games\CityGraph`。
3. 双击启动，在首页选择新建地图或打开存档。

可以把 `CityGraph.exe`、`运行说明.txt` 和本 README 放在同一个文件夹中分发，程序不依赖源码目录或素材文件夹。

程序需要 Microsoft Edge WebView2 Runtime（Windows 11 通常已自带）。如果系统提示缺少运行环境，请从 [微软 WebView2 页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Runtime。

启动动画可以点击或按键跳过，之后会进入**开始页面**，不会自动打开 Riverside Bay。

你可以在首页选择：

| 入口 | 适合什么情况 |
| --- | --- |
| **新建地图** | 从空白画布开始设计城市 |
| **继续最近存档** | 打开保存时间最新的地图，有存档时显示 |
| **我的存档** | 根据地图名称、缩略图和时间选择具体存档 |
| **导入地图** | 在线下载真实街区，或读取本地 `.osm` 文件 |
| **打开示例城市** | 主动打开 Riverside Bay，熟悉各种工具 |

### 开始前的设置

首页可以设置**中文／英文、背景音乐开关、音乐音量、自动保存开关**，这些偏好会自动记住。进入地图后，还能在右上角 **设置** 中调整界面透明度、全屏、快捷键、自动保存间隔、保留份数和经济单位。

首页停留期间不会自动保存空白占位地图。若上次意外退出留下恢复快照，会优先询问是否恢复；恢复成功后继续原来的工作。

### 新建地图怎么选

1. 填写地图名称，例如“星港市”；名称之后可以在顶部直接修改。
2. 选择画布大小：小地图约 **6 × 6 km**，中地图 **12 × 12 km**，大地图 **20 × 20 km**，也可以选择无限画布。
3. 地形默认是**平地**；需要自然水域时可选择湖泊地形并设置湖泊数量。
4. 点击 **创建**。初次游玩建议先用小地图，逐步扩展。

有限画布可通过左侧“画布边界”调整，也可以在 **设置 → 外观界面 → 画布** 中展开尺寸选项或切换无限画布。

## 十分钟完成第一片街区

![从道路到完整城市的四步示意](docs/images/quick-start.png)

1. **新建一张平地地图**，起一个名字，使用滚轮把视野调整到合适比例。
2. **画出主干道**：选择左侧“道路”，设置道路类型和宽度，依次点击起点、终点。先画一条长路，再增加支路。
3. **围成街区**：把几条地面道路接成闭合区域；也可以使用“街区”工具，设置行列数后点击两个对角点，快速生成网格路网。
4. **设置用地**：选择“分区 → 道路填充”，挑选住宅、商业或办公等类型，点击道路围合的区域。
5. **放入建筑**：进入“建筑”，先尝试矩形预设；也可以在闭合街区里生成一组建筑，调整密度、边长和退界距离。
6. **增加设施**：选择餐厅、医院、商店等设施，再点击合适的建筑内部放置。
7. **补上自然环境**：画一片公园或一条河，为区域、道路和设施填写名称。
8. **点击顶部“保存”**。之后可继续加公交、地铁、大学校区和行政区。

分区只描述用地，建筑和设施需要使用各自的工具创建。想修改刚完成的操作，可点击顶部撤销。

## 界面与基本操作

- **顶部工具栏**：城市名称、框选、吸管、测量、撤销／重做、保存和设置。
- **左侧工具栏**：选择、拖动、画布边界、道路、街区、建筑、分区、交通、行政区、设施、绿化、大学、水体和城市信息。
- **右侧属性面板**：选中对象后查看或编辑名称、类型、颜色及其他属性。
- **右上角图层按钮**：控制道路、建筑、设施、水体、分区、网格等图层是否显示。
- **右下角视图控件**：定位视图、放大、缩小；指南针用于恢复北向。

### 鼠标与快捷键

| 操作 | 方法 |
| --- | --- |
| 缩放地图 | 鼠标滚轮，或右下角 `+` / `−` |
| 平移地图 | 切换“拖动”工具后左键拖动；默认也可用 `W/A/S/D` |
| 旋转地图 | 中键拖动；默认也可用 `Q/E` |
| 选择对象 | “选择”工具下点击对象 |
| 编辑形状 | 切换到对应工具的“编辑”模式，再拖动对象、边或顶点 |
| 完成自由轮廓或折线路径 | `Enter` 或双击，具体以工具提示为准 |
| 取消当前绘制 | `Esc` |
| 删除对象 | 选中并进入适用的编辑模式后按 `Delete` / `Backspace`，或点属性面板删除 |
| 撤销 / 重做 | 顶部按钮；`Ctrl+Z` / `Ctrl+Shift+Z` |
| 框选复制 / 粘贴 / 复制一份 | 框选模式下 `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 全屏 | `Alt+Enter`，或设置中的全屏开关 |
| 保存 | 点击顶部“保存” |

在输入框中打字时，地图快捷键不会抢占普通输入。平移和旋转按键可在 **设置 → 快捷键** 修改。每个工具面板底部都有当前模式的操作提示。

## 各类工具怎么玩

### 吸管与测量

- **吸管**：点击顶部吸管，再点地图上的道路、建筑、用地分区或绿地。程序复制绘制参数并自动切换到对应绘图工具；道路包含类型、实际宽度和地面／高架／隧道属性，建筑包含用途、风格、楼层和高度，分区包含颜色与图标，绿地包含颜色与透明度。隐藏图层不参与吸取；`Esc` 或右键取消。
- **距离尺**：打开顶部“测量”菜单，选择“距离尺”，拖动两点，或依次点击起点、终点，显示米／公里距离。
- **矩形面积尺**：选择“矩形面积尺”，拖动或点选两个对角点，显示地图坐标轴方向的长、宽和面积。旋转视图不会改变世界坐标测量值。
- 松手后结果保留，缩放或平移后标记仍跟随地图；再次测量会替换结果。`Esc`、右键或“清除测量”清除标记，“取消”退出工具。测量不会改动存档中的地图对象。

### 道路与街区

- 选择道路类型、宽度、地面／高架／隧道结构，然后使用直线、曲线、平行线、圆形或多边形等模式绘制。
- 靠近已有道路和节点时，观察吸附提示，再点击连接。需要跨越水域时，可调整道路结构和跨水设置。
- 编辑模式可移动节点、控制点和道路。右键菜单可提供对应位置的增点、删点等操作。
- “街区”工具适合快速铺设规则网格；不规则城区可以逐条手绘。

**想做道路填充？** 道路必须真正连接并围成闭合区域。仅在视觉上接近、存在缺口，或者使用不同层级的道路，都可能无法形成可填充地块。

### 建筑

- **预设放置**：矩形、L/U/H 形、庭院和环形等轮廓，适合快速搭建街区。
- **对角矩形**：先点一个角，再点对角。
- **自由轮廓**：逐点绘制，按 `Enter` 或双击完成。
- **道路围合生成**：在有效闭合地块内创建贴合轮廓的建筑，或按边长、密度、间距和退界参数生成多栋建筑。
- **编辑**：移动建筑、拖动顶点或边；启用外扩后可拉出新的翼楼。

建筑用途、风格、楼层、高度和名称都可在工具或属性面板中调整。自动生成只有在点击地块后才开始计算，鼠标悬停不会生成建筑。

### 用地分区与行政区

**用地分区**表示住宅、商业、教育、医疗、工业、办公、旅游等用途，可以自由画轮廓，也可以填充道路围合区域。切到编辑模式后可调整形状、透明度、图标和名称。

**行政区**用于组织较大的城市范围。绘制边界后，可填写名称和 GDP 等信息，并查看区域内的设施、大学及企业统计。它与“住宅／商业”等功能用地区别开来使用。

### 水体与绿化

- 自由湖泊：沿岸线逐点绘制。
- 矩形随机湖泊：指定两个对角点，在范围内生成不规则湖形。
- 河流：沿中心线点击，设置河宽，再完成绘制。
- 岛屿：在水体内部绘制岛屿绿化，轮廓不要接触岸线。
- 公园／绿地：自由绘制或道路填充，并设置色调、透明度和名称。

OSM 中带岛屿或内孔的区域可能会转换成多个可编辑分片；同一导入水体的名称和水面会合并显示，避免重复地名和内部切割线。

### 公共设施与企业

选择设施种类及颜色后，在地图上点击放置。普通设施通常需要落在建筑内部；大学专用设施需要放在合适的校区内，无法放置时请看界面提示。

企业地点可以关联同一企业档案，设置总部、名称、Logo、简介、Tag、市值及校友大学。多处地点可以共同属于一家企业，地点信息和企业公共资料分别编辑。

### 大学与医院

![大学校区与附属单位的三步示意](docs/images/university-workflow.png)

1. 选择“大学 → 大学分区”并绘制校区。
2. 在面板中创建大学，或把新校区加入已有大学。
3. 填写名称、校徽、类型、排名、简介和其他资料。
4. 在校区内放置学院、实验室、图书馆、宿舍、食堂等设施。
5. 在大学详情中添加附属学校、医院、设施或校友企业，再到地图上选择对应对象。

医院也可以组织多个院区，填写等级、床位数、专科、排名和大学附属关系。大学和医院的信息面板提供查看与编辑入口。

### 公交、高铁与地铁

**公交**

1. 先确保道路连通。
2. 选择“交通 → 公交 → 创建”，沿道路依次放置站台。
3. 至少两个站点后按 `Enter` 完成开放线路；点击首站可闭合成环线。
4. 创建中可用右键或 `Ctrl+Z` 撤回上一站，`Esc` 取消。
5. 切到编辑模式，修改线路颜色、名称、站点和站序；右键线路可添加站点。

**高铁／铁路**：先铺设轨道，再沿轨道放置车站，最后依次选择车站建立运营线路。线路会沿已有轨道寻路。

**地铁**：在线路模式下依次点击位置，每个落点会创建车站并连接轨道；靠近已有车站可形成换乘。完成后可编辑站名、颜色、站序，增加车站或延长线路。

### 机场、航班线与轮渡

1. 进入 **交通 → 飞机** 或 **交通 → 轮渡**，选择“机场分区”或“码头分区”。
2. 逐点画出区域，按 `Enter` 或双击完成。可以先填写名称，留空会自动命名；地图上显示飞机或轮船图标。
3. 建立至少两个同类型站点后，切到“航班线”或“轮渡航线”，填写名称并选颜色。
4. 点击出发机场／码头，再点击目的地完成航线。两机场之间默认显示弧线；途中点击空白处可添加转折点，轮渡可按水道手动规划路径。
5. 创建中右键或 `Ctrl+Z` 撤回一个转折点，`Esc` 取消。切到“编辑”后，可拖动区域、区域顶点或航线转折点。
6. 右侧属性面板可修改名称、颜色和起终点，交换航向、移除转折点或删除线路。删除机场／码头时关联航线一并移除，撤销可一起恢复。

已有的机场用地分区也可直接作为航班端点。机场和码头图标由交通图层控制；进入对应交通工具可查看该类型的全部航线。

### 城市信息、日报与助手

“信息”面板集中展示大学、医院、企业、行政区及交通等资料，可以点击条目定位到地图对象。市值和排名等信息来自当前城市档案。

城市日报可依据编辑事件生成；配置 DeepSeek 后可使用 AI 日报和城市助手，未配置或服务不可用时日报会尝试使用本地模板。AI 密钥在 **设置 → DeepSeek AI** 中填写，保存在本地设置，不写入地图存档。

## 导入真实地图

### 在线下载 OSM

桌面版可以在首页点击 **导入地图**，或在已打开地图中进入 **设置 → 城市与存档 → 导入地图 → 在线下载地图**。

1. 在“选择导入内容”中勾选道路、建筑、水体、绿化、分区和设施，支持全选／全不选。
2. 搜索地点，例如“西湖”，点击包含正确城市的结果；也可以直接输入 `30.253,120.165` 这样的纬度、经度。
3. 点击“框选区域”并拖出矩形，或选取视野中心 1 km²；也可以展开经纬度字段精确输入范围。
4. 点击 **下载并预览**。界面会显示字节和分块进度，支持取消。
5. 下载后沿用你的图层选择，可继续勾选、裁剪并确认。

下载器没有额外的 **25 km² / 单边 10 km** 选区限制。OSM 服务端节点或选区超限时会继续分块请求，再合并去重。当前原始下载总量上限为 **32 MB**；OSM 官方接口按选区返回数据，图层勾选决定最终写入游戏地图的内容。

在线地图数据来自 OpenStreetMap 官方 API，地点搜索来自 Photon / komoot。来源信息可通过界面中的“地图来源”展开查看。地点搜索和数据下载遇到临时连接失败、传输中断或服务器错误时，最多尝试三次；界面区分搜索失败和下载失败，提示连接、超时、限流等原因。重试等待期间仍可取消下载，不会导入未收完的数据。若服务要求较长时间后重试，程序会直接提示稍后再试。

### 读取本地文件

切到 **本地文件 / 导入预览**，选择未压缩的 OSM 0.6 XML 文件（`.osm` 或 `.xml`）。从 OSM 或 BBBike 下载的压缩包应先解压；PBF、GeoJSON 和压缩包目前不能直接导入。

项目附带：

- `imports/hangzhou-west-lake-full.osm`：西湖周边道路、建筑、绿地、水域、分区与设施。
- `imports/hangzhou-west-lake-streets.osm`：同一地区的街道版本。

本地文件最大 32 MB，最多处理 50 万个 OSM 元素、5 万个导入对象／道路段；用于转换的区域跨度目前不超过 200 公里。

### 只截取一小块，再放进已有存档

1. 在导入预览图上拖动矩形框，选取所需区域；松开鼠标后，图层数量随之更新。
2. 也可以使用“选取中心 1 平方公里”，或精确调整来源选区。
3. 选择 **添加到当前地图**。如果是从启动首页进入，则先使用“导入为新地图”；合并需要先打开目标存档。
4. 点击 **在存档地图上选择位置**，移动鼠标查看半透明预览。
5. 左键点击确定中心，返回导入窗口后点击 **导入所选区域**。也可直接填写 X/Y 坐标。

选位置时：滚轮缩放、中键／右键拖动地图；方向键微调 10 米，`Shift+方向键` 微调 100 米，`Enter` 确认，`Esc` 取消。

导入按真实米制比例放置，保留当前地图名称与存档位置，必要时扩展画布，整次合并支持一次撤销／重做。导入道路不会自动与原有路网接通，可以之后手工连接。

### 哪些 OSM 信息会保留

名称、地址、道路等级、桥梁／隧道结构、建筑轮廓、已有高度与楼层，以及对应的用地分类会转换为可编辑对象。原始 OSM 类型、ID 和标签也会随对象保存。

缺少尺寸时使用默认值；缺失节点和无效轮廓会跳过并显示统计。原始文件没有的内容无法自动补齐，例如街道版文件不会产生建筑。单行道和转向限制目前不参与交通模拟。

## 保存、加载与恢复

- **保存**：首次保存会创建存档；之后更新当前存档。
- **另存为**：为方案分支保留单独副本，例如“旧城改造方案 A”。
- **打开存档**：首页和设置页按城市名称分组展示，展开后可查看手动存档和自动副本的时间线。新建的同名城市独立分组、独立存储，城市改名仍保留原来的历史。
- **查找存档**：搜索城市或存档名称，可筛选手动／自动存档。默认只展开最近城市，其他城市按需展开，缩略图延迟加载。
- **自动保存**：可设置间隔和每座城市的保留份数；只清理该城市超出的自动副本，不影响其他城市或手动存档。打开自动副本后，手动保存会建立或更新手动存档。
- **意外退出恢复**：下次启动会询问是否恢复临时快照；正常退出时可以保存后退出、放弃修改或取消退出。

Windows 桌面版的 `save/` 文件夹保存城市，`data/` 保存本地设置、恢复数据等。源码运行时位于项目根目录；独立程序运行时通常位于程序目录。备份或分享城市时，请复制**整个存档文件夹**，包括其中的资源文件。

浏览器版的数据保存在当前浏览器的站点存储中；清除站点数据或更换浏览器会影响可见存档。在线下载和桌面文件系统操作以 Tauri 版为准。

## 常见问题

### 为什么找不到导入的对象？

检查导入内容是否勾选、对应图层是否显示，以及放置位置是否正确。可以缩小视野查看整体；如果填了较大的 X/Y 坐标，内容可能在较远位置。

### 为什么道路围合区域不能填充？

检查路口是否真正连接、边界是否闭合，以及道路是否处于适用的地面层级。过窄或自相交的区域也可能无法生成有效地块。

### 为什么设施放不下？

普通设施需要合适的建筑承载，大学专用设施需要对应校区。先放建筑或画校区，再根据底部提示放置设施。

### 导入范围大时会卡吗？

真实地图可能有成千上万个对象。可以先在预览中截取小区域、只勾选需要的图层，再分批合并。减少屏幕上的设施文字、复杂对象和不需要的图层，也能改善交互体验。

### 示例城市去哪了？

在启动首页点击 **打开示例城市**。它是可选的练习地图，不再作为每次启动的默认场景。

### 有些信息像“经济数据”，是不是会自动增长？

目前它们主要用于城市设定、统计展示和内容创作。可以自行设定大学排名、企业市值和行政区 GDP，再用信息面板组织这座城市的故事。

## 从源码运行与构建

需要 Node.js 20.19+ 和 npm。开发桌面版还需要 Rust、Windows C++ 构建工具及 WebView2 Runtime。

```powershell
git clone https://github.com/zihayi/CityGraph.git
cd CityGraph
npm install
npm run tauri:dev
```

只运行浏览器预览：

```powershell
npm run dev
```

浏览器打开 <http://127.0.0.1:5173>。

测试与构建：

```powershell
npm test
npm run build
npm run tauri:build
```

Windows 可执行文件位于 `src-tauri/target/release/citygraph.exe`，安装包位于 `src-tauri/target/release/bundle/`。也可使用 `npm run tauri:build -- --no-bundle` 只生成可执行程序。

生成主目录的便携版（推荐用于给玩家分发）：

```powershell
npm run package:portable
```

这条命令从已纳入 Git 的构建输入创建干净打包目录，排除个人 Logo、存档和本地附加素材，构建后自动复制为主目录的 **`CityGraph.exe`**。开发新功能时，请先将新的构建必需文件纳入版本控制，再制作便携版。普通玩家只需运行 exe，无须执行上述开发命令。

个人校徽／企业 Logo 目录（`assets/university/Logo/`、`assets/enterprise/Logo/`、`assets/logo/`）由 Git 忽略，本地文件可以继续使用。面向他人发布程序时，请从干净的仓库检出目录构建，以仅打包仓库资源；本地素材目录中的图片可能被本机构建自动收集。

技术栈：React 19、TypeScript、PixiJS、Zustand、Leaflet、Vite、Vitest、Tauri 2。
